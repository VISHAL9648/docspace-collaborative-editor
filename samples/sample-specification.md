# DocSpace Architecture & Collaboration RFC

DocSpace is a **lightweight collaborative document editor** built with *Next.js 16*, *Tiptap*, and *Supabase PostgreSQL*.

## Core Capabilities
- Secure authentication with email and password
- Real-time PostgreSQL Row Level Security (RLS)
- Rich text editing powered by Tiptap
- Safe document import for Markdown and Plain Text

## Next Milestone Steps
1. Deploy migrations to Supabase
2. Test document sharing permissions
3. Verify autosave persistence
